## What lives here

This repository owns the organization-facing layer: the public profile, community files, and default presentation used by Aniraku on GitHub. Product code stays in the project repositories.

| Area | Location |
|:--|:--|
| Organization profile | [`profile/README.md`](profile/README.md) |
| Profile assets | [`profile/assets/`](profile/assets/) |
| Web client | [Aniraku](https://github.com/Aniraku/Aniraku) |
| Backend | [Aniraku-Backend](https://github.com/Aniraku/Aniraku-Backend) |
| Android client | [Aniraku-App](https://github.com/Aniraku/Aniraku-App) |
| Community | [Discord](https://discord.gg/aniraku) |

## Where to contribute

Use the contribution guide in the repository that owns the change. The profile repository is for organization-level presentation; frontend, backend, and Android changes belong in their respective projects.

When opening an issue or pull request, include the affected project, a short reproduction or change summary, and screenshots or logs when they help explain the problem. Keep credentials, tokens, cookies, and private operational details out of public issues and commits.
