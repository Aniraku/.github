## Built around a better viewing experience

**Aniraku** is a free, open-source anime streaming platform. We build thoughtful tools that make anime discovery, playback, and personal libraries feel fast, focused, and dependable.

## What we care about

| Focus | Our approach |
| :-- | :-- |
| **Open source** | Build in public and welcome practical contributions from the community. |
| **Thoughtful product** | Keep the interface calm, quick, accessible, and centered on the content. |
| **Reliable discovery** | Help viewers find something worthwhile through useful search, filters, and schedules. |
| **Respectful participation** | Create a constructive space for users, contributors, and maintainers. |
